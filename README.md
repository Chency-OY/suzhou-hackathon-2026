# 医学沟通训练台

面向医药代表的合成情境演练。用户选择课程和场景，与虚构医生对话，结束后逐句回看自己的表达。当前提供「通用医学沟通」与「信尔美产品资料」两组课程。通用课程不读取产品知识库；产品课程以仓库中的公开资料为基础。

## 当前可用

- 16 个经人工整理的合成场景（通用 12、信尔美 4），支持科室、难度和情境筛选。
- 桌面游戏式任务界面：在任务大厅选课程、筛选情境并直接开始演练；对话关卡、练习档案与逐句复盘保持统一视觉。
- 会话创建、对话、结束、回放；练习记录列表保存在当前浏览器，完整对话保存在服务器 SQLite。
- 复盘展示原句、明确识别到的沟通行为和下一次练习建议；AI 参考分只用于训练，正式考核仍需人工审核。
- 前线日记：拜访后可在安卓 App 或支持语音识别的浏览器中口述第一感受，AI 整理为简短回忆、医生反馈、改进动作、下次准备和待核对说法；原话保留，日记仅同一账号可读。
- 从日记可发起新一轮虚构演练：只取沟通体验线索，医学判断被隔离，不会写入医生画像；删除日记后，后续演练不再读取其线索。
- 日记中的医学说法可在「核对日记中的说法」中与本地说明书整理条目对照。只有能逐字找到原话、且资料能定位说明书章节时才可能给出相符或冲突线索；否则显示资料不足。附原说明书链接供人工复核；未确认作者身份的论文不会参与裁定。
- 学术雷达：主动输入姓名与医院，AI 检索论文、会议和演讲网页，并整理带来源摘录的回答；公开论文索引补充候选资料。网页和同名作者均为待核候选，搜索不保证完整，不直接当作已核实的医生画像。
- 从学术雷达可主动选择近期、带来源摘录的同名候选做证据表达演练：模拟医生会追问资料出处和适用范围，页面保留候选来源；不把候选经历归给真实医生。
- 训练复盘：结束虚构演练后由 AI 给出六维训练参考分和可跳转到原句的点评；AI 暂不可用时只保留沟通信号。明显合规红线需规则命中和模型复核才封顶，医学事实及正式合规仍须人工审核。
- 信达产品目录：20 款已上市产品与 6 个后期项目可直接在站内查看靶点、药物形式、主要领域和阶段；每款产品有三道可语音回答的基础资料测试，AI 按已核对资料判断并展示参考要点。上市前研究方向不会当作获批适应症。
- 学术交叉核对：用户主动将自己的日记原话与同名雷达网页摘录对照，只提示学术活动中可能有出入的线索，并展示双方原文与来源链接。身份未确认，结果不自动改写模拟医生画像；药品与医学说法仍走说明书对照。
- 日记驱动练习：用户主动选用自己的日记后，模拟医生会针对再次出现的、日记中有原话依据的表达方式提出异议；有明确原话依据的忙碌或不耐烦观察会临时改变这场练习的对话节奏。学术活动和医学判断不进入角色偏好，信任度和评分不受日记观察影响。
- 语音演练：自由对话可语音输入；用户可逐句朗读模拟医生台词，或主动开启新回复的自动朗读。安卓 App 调用系统语音识别及中文语音播报，语音不可用时保留文字操作。
- 应用图标：蓝底白色对话气泡与三段语音线，网页和安卓使用同一视觉符号，缩小到手机桌面尺寸仍能辨认。
- 场景预筛、人工审核清单和隐藏设定泄露检查。人工审核状态仍为 `pending`，未替带教人员作通过决定。

公网预览首页：<https://chenxi-ouyang.online/rep-trainer/>（无需登录）；进入训练后可免登录试用或创建账号，训练内容和 API 保留访问限制，凭据不在仓库中。首页和训练页使用[信达生物官网公开 Logo](https://www.innoventbio.com/)作视觉参考，并明确标注为非官方原型。公网对话与沟通信号判断使用 AI，固定三选一教学反馈仍来自预设课程；AI 暂不可用时使用备用模拟回复。医生回复和训练提示不能用于医学或合规判断，产品事实仍需以最新获批资料核对。

安卓安装包从首页「下载安卓 App」获取。App 打开前线日记页，调用手机已有的语音识别服务转文字，日记在网站账号中保存。语音识别服务是否可用取决于手机配置；识别结果保存前可编辑。安装包使用服务器私有发布密钥签名，签名文件与密码不进入仓库。

## 本地运行

```bash
uv venv .venv
uv pip install --python .venv/bin/python -e '.[dev]'
cd frontend && pnpm install && pnpm build && cd ..
VECTOR_STORE=simple .venv/bin/python scripts/seed.py
VECTOR_STORE=simple .venv/bin/uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

运行测试：`bash scripts/verify_t11_t15.sh`；运行本机冒烟：`.venv/bin/python scripts/e2e_smoke.py --base http://127.0.0.1:8000 --with-session`。

## 内容与资料

- 课程目录：`data/programs.json`；画像与场景：`data/personas/personas.jsonl`、`data/scenarios/scenarios.jsonl`。
- 信尔美资料从[信达生物公开说明书](https://img.innoventbio.com/product/W10030842001.pdf)整理；`data/sources/label.md` 记录录入来源和口径。两份不同适应症的说明书不得混用。
- 所有医生、对话和案例均为合成。请勿输入真实患者或医生的个人信息。

部署步骤、回滚和服务日志见 `docs/DEPLOY.md`；任务与已知限制见 `docs/PROGRESS.md`、`docs/INTEGRATION_ISSUES.md`。协作时先拉取 GitHub 最新提交，检查差异后再合并；服务器只部署已经提交并推送的版本，避免覆盖队友工作。
